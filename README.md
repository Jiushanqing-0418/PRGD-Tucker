## Preconditioned Riemannian Gradient Descent (PRGD) Algorithm for Low-Multilinear-Rank Tensor Completion
* This project implements the PRGD algorithm established in [Preconditioned Riemannian Gradient Descent Algorithm for Low-Multilinear-Rank Tensor Completion](https://www.tensortoolbox.org/), which has been accepted by ICML 2025.
* File test.m compares PRGD with RGD and ScaledGD for the tensor completion task.
  * To run this file, please download the [tensor toolbox](https://www.tensortoolbox.org/) and add the package at the same directory level as test.m.
